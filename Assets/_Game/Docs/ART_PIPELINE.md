# Art and rendering pipeline

## Production asset requirements
Every production prop is a real 3D mesh (not a 2D sprite) with:
- Albedo/base color
- Tangent-space normal
- Ambient occlusion
- Metallic and smoothness packed into a mask where appropriate for URP Lit
- LOD0/LOD1/LOD2 meshes with screen-relative transition thresholds
- Correct scale, collision proxy and pivot/origin

## Surface authoring
Use tileable PBR materials for wood grain, oxidized sheet metal, rough stone/moss, soil and grass. Terrain fallback textures generated by WorldGenerator are only temporary readable placeholders, not the final PBR art set.

## Mobile texture import
Create ASTC overrides in each Texture Importer platform section after source textures are approved:
- ASTC 6x6 for ordinary albedo/normal maps on medium devices
- ASTC 4x4 for hero/close-up assets when memory allows
- ASTC 8x8 for distant/less detailed surfaces
Always compare visual quality and memory use on target devices. ASTC support must be checked for the actual Android GPU.

## Lighting
URP real-time sun, soft shadows and a lightweight color/fog cycle are the baseline. The current fog is distance fog, not volumetric fog. Volumetric fog and real-time GI are not enabled by default because they can exceed mobile GPU budgets; assess alternatives and quality tiers after profiling.
